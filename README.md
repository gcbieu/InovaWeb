## Visão geral

**InovaWeb** é um projeto de interface web que apresenta a proposta de uma marca fictícia voltada a inovação e soluções digitais. A página organiza, em uma experiência de navegação única, conteúdos sobre **automação com inteligência artificial, desenvolvimento web, consultoria digital e formação em tecnologia**.

O objetivo do projeto é praticar a construção de uma **landing page institucional**, dando atenção à hierarquia visual, à organização das informações e à apresentação de diferentes serviços em uma mesma interface.

> **Nota:** este repositório é uma demonstração de front-end. Serviços, números de alunos, disponibilidade de suporte, preços e contatos exibidos na página são conteúdos da apresentação e não comprovam a operação comercial de uma empresa.

## O que a página apresenta

| Seção | Conteúdo |
| --- | --- |
| **Início** | Apresentação da identidade e da proposta InovaWeb |
| **Sobre** | Texto institucional e indicadores apresentados como parte do conceito do site |
| **Serviços** | Cards de automação com IA, desenvolvimento web e consultoria digital |
| **Formação** | Apresentação dos cursos Engenharia de Prompt, Front-End com IA e Desenvolvimento Fullstack AI |
| **Contato** | Chamada para contato com informações exibidas no layout |

## Tecnologias

- **HTML5:** estrutura semântica e organização do conteúdo.
- **CSS3:** estilos, composição visual e adaptação da interface.
- **GitHub Pages:** publicação estática do projeto.

A versão pública do repositório contém `index.html`, `style.css` e uma pasta de favicon. Não há indicação de back-end ou integração real com serviços de IA neste projeto.

## Como executar localmente

Como o projeto é estático, não há dependências ou instalação de pacotes obrigatórias.

```bash
git clone https://github.com/gcbieu/InovaWeb.git
cd InovaWeb
```

Abra o arquivo `index.html` no navegador. Para desenvolver, você também pode usar a extensão **Live Server** do VS Code.
